# Modern Dark Chart Theme — اسکریپت متاتریدر ۵

اسکریپت `ModernDarkChartTheme.mq5` همان تم تیره‌ی تصویر را روی چارت متاتریدر ۵ اعمال می‌کند:
پس‌زمینه‌ی تیره، بدون گرید، کندل‌های فیروزه‌ای/قرمز و محورهای طلایی.

## نصب

۱. در متاتریدر ۵ مسیر `File > Open Data Folder` را باز کنید.
۲. فایل `ModernDarkChartTheme.mq5` را در `MQL5/Scripts/` کپی کنید.
۳. در MetaEditor فایل را باز کنید و `F7` (Compile) را بزنید.
۴. در متاتریدر `Ctrl+N` (پنجره‌ی Navigator) → بخش **Scripts** → روی
   **ModernDarkChartTheme** دوبار کلیک کنید (یا روی چارت بکشید).
۵. پنجره‌ی ورودی‌ها باز می‌شود؛ تنظیمات را در صورت نیاز تغییر دهید و **OK** را بزنید.

## ورودی‌ها

| گروه | ورودی | توضیح |
| --- | --- | --- |
| Scope | `InpApplyAllCharts` | اعمال تم روی همه‌ی چارت‌های باز (پیش‌فرض: فقط چارت جاری) |
| Scope | `InpSaveTemplate` / `InpTemplateName` | ذخیره‌ی نتیجه به‌صورت تمپلت `.tpl` برای استفاده‌ی بعدی |
| Palette | رنگ‌ها | پس‌زمینه، متن/محور، بدنه‌ی کندل صعودی و نزولی، خطوط Bid/Ask/Last و سطوح حد ضرر |
| Layout | گرید، جداکننده‌ی دوره، حجم، OHLC، خطوط Bid/Ask، شیفت و اسکرول خودکار |
| Indicators | `InpAddMA`, `InpMAPeriod`, `InpMAMethod`, `InpAddRSI`, `InpRSIPeriod` | افزودن میانگین متحرک روی چارت و RSI در ساب‌ویندو |

رنگ‌های پیش‌فرض (همان پالت تصویر):

- پس‌زمینه `#08090C`
- متن و محورها (طلایی) `#E2B44A`
- کندل صعودی `#00C9A7`
- کندل نزولی `#E9384F`

## چند نکته

- اسکریپت **یک‌بار** اجرا می‌شود و تنظیمات چارت را تغییر می‌دهد؛ چیزی روی چارت باقی نمی‌ماند
  و منابع سیستم را مصرف نمی‌کند.
- اگر `InpSaveTemplate` روشن باشد، تمپلت در
  `MQL5/Profiles/Templates/ModernDark.tpl` ذخیره می‌شود و بعداً از
  `Charts > Template > Load Template` روی هر چارتی قابل بارگذاری است. برای اینکه هر چارت
  جدید خودکار با همین تم باز شود، آن را با نام `default` ذخیره کنید
  (`InpTemplateName = "default"`).
- اسکریپت اندیکاتورهای تکراری اضافه نمی‌کند؛ اگر روی چارت از قبل MA یا RSI باشد، رد می‌شود.
- رنگ خود خطوط MA و RSI از تنظیمات پیش‌فرض اندیکاتورهای داخلی متاتریدر می‌آید. متاتریدر ۵ API
  برای تغییر رنگ اندیکاتوری که با اسکریپت اضافه شده ندارد؛ برای رسیدن به خط طلایی تصویر،
  یک‌بار روی خط دوبار کلیک کنید (یا `Ctrl+I`) و رنگ را روی `#E2B44A` بگذارید — بعد تمپلت را
  دوباره ذخیره کنید تا رنگ در تمپلت بماند.
- برای برگشت به حالت قبل کافی است تمپلت قبلی خود را دوباره روی چارت بارگذاری کنید؛ پس اگر
  چیدمان فعلی‌تان مهم است، پیش از اجرا از `Charts > Template > Save Template` یک نسخه بگیرید.
